# apps/rait/web — RAIT reviewer webapp (placeholder)

Recursos Administrativos de Infrações de Trânsito: webapp for ticket-contestation
review, work distribution among reviewers (@stynx-nyx/worklist) and 2nd-tier JARI
appeal boards. Angular 22 (STYNX 1.3.1), angular-flow + packages/ui.

**Built in Phase 3 (W3.4)**, on the RAIT backend modules of backend/domains/inf.

Especificação completa do frontend (módulos, rotas, componentes, jornadas, ações, dependências de
backend): [docs/framework/arch/rait-web-frontend.md](../../../docs/framework/arch/rait-web-frontend.md).
