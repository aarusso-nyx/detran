# apps/dashboard/web — DASHBOARD staff webapp (placeholder)

Staff webapp de monitoramento transversal, organizado pelo corpus em quatro blocos de
indicadores — A (teto legal), B (deveres periódicos), C (SLA operacional), D (saúde técnica) —
e quatro camadas de acesso N0…N3 (`RN-DASH-170`), cada uma restringindo o que a tela expõe por
papel e domínio. Grows a panel-set every phase.

**Skeleton built in Phase 3 (W3.6)**; portal/notification panels in Phase 4 (W4.5);
field-ops/sinistro panels in Phase 5 (W5.3).

Especificação do frontend, contrato de rotas, erros e pacote de construção: `docs/framework/arch/dashboard-frontends.md`, `dashboard-route-contract.md`, `dashboard-error-catalog.md`, `dashboard-build-pack.md` (2026-09-13).
