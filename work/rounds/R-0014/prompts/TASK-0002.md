**A. Verificador (`tools/parameters/tests/verify-usage.test.mjs`, `node:test`).** Executa
`node tools/parameters/verify.mjs --check-usage --source <arquivo> --catalogue <md>` — a opção

1. dado catálogo com allowlist contendo `portal.errors` quando o arquivo tem `'portal.errors.not_found'`
   então exit 0 e nenhuma linha `unknown parameter literal`;
2. dado o mesmo catálogo quando o arquivo tem `'portal.foo.bar'` (namespace fora da allowlist)
   então exit 1 e stderr contém `unknown parameter literal portal.foo.bar`;
3. dado catálogo cuja allowlist lista `portal.read_cache_ttl_minutes`-like colisão — i.e. um
   namespace `rait.timer` **e** uma chave de parâmetro `rait.timer.T-DEF` nas tabelas — então
   exit ≠ 0 e stderr cita o namespace em colisão;
4. dado allowlist com namespace de prefixo estranho (`foo.bar`) então exit ≠ 0 com diagnóstico;
5. dado catálogo com a tabela de namespaces malformada (três colunas) então exit ≠ 0 com arquivo e
   linha;
6. dado catálogo **sem** a seção de namespaces então o comportamento é o atual (literal
   `'portal.errors.not_found'` é candidato → exit 1) — a allowlist é opcional na gramática, mas
   nunca silenciosa;
