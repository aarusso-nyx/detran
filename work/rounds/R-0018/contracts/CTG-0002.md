### 5.3 Prova esperada (o código de saída é lido da forma **sem** `-v`)

Medido nesta tarefa (git 2.50.1): com `-v`, `git check-ignore` sai com **0** também quando o
caminho casa uma **negação** (imprime a linha `!…`), isto é, quando o caminho **não** é ignorado.
Por isso o código de saída (0 = ignorado, 1 = não ignorado) vem de
`git check-ignore --no-index <caminho>`; o `-v` serve só de diagnóstico (qual linha casou). Sem
`--no-index`, arquivos já rastreados nunca são reportados (exit 1 sempre) — não prova nada.

| Caminho                                            | `git check-ignore --no-index <caminho>` | `git check-ignore --no-index -v <caminho>` (diagnóstico)                    |
| -------------------------------------------------- | --------------------------------------- | --------------------------------------------------------------------------- |
| `work/rounds/R-0018/reports/TASK-0001.md`          | exit 1 (não ignorado)                   | `.gitignore:16:!work/rounds/*/reports/**` (antes: `.gitignore:10:reports/`) |
| `dist/x`                                           | exit 0 (ignorado)                       | `.gitignore:3:dist/`                                                        |
| `apps/dashboard/web/src/app/features/reports/x.ts` | exit 1 (não ignorado)                   | `.gitignore:18:!apps/*/*/src/app/features/reports/**`                       |
| `reports/x`                                        | exit 0 (ignorado)                       | `.gitignore:10:reports/`                                                    |
