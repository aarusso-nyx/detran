# A3.1 — decisão semântica para 54 TASKs legadas com `db_isolation: none`

**Papel:** Architect. **Estado:** proposta sem efeito até decisão específica do Owner. **Fonte:** `reports/A3-source-map.md` lista individualmente as 54 TASKs, e `contracts/CTG-0003-A3.md` fixa sidecar byte a byte e vínculo por SHA-256.

O schema `task.schema.json` 2.0.0 só aceita `database` ou `cluster`; não contém valor fiel para “não adquire banco”. Nenhum plano histórico consultado prova que as 54 TASKs com `none` tenham recebido um banco isolado. Converter o campo como observação histórica seria incorreto.

## Alternativa proposta para decisão do Owner

Adotar uma **interpretação normativa prospectiva** do campo canônico para esse conjunto fechado: `db_isolation: database` significa “se a TASK voltar a adquirir recurso de banco sob a governança atual, o limite mínimo autorizado é banco dedicado”. Não significa que um banco tenha sido usado na execução histórica. Cada TASK conserva os bytes originais `none` no sidecar A3, recebe tags `legacy-db-isolation:none` e `legacy-db-policy:prospective-database`, e o relatório antes/depois declara que o valor canônico é decisão nova do Owner, sem prova retroativa de isolamento. Nenhuma outra tarefa recebe essa regra por semelhança.

O normalizador só poderá aplicar a regra à allowlist exata de 54 caminhos e hashes originais do mapa fechado, após teste Inspector de positivo, negativo fora da lista e corrupção do sidecar. `verify:round-tasks` e o schema permanecem inalterados. O relatório final separa “valor canônico por decisão” de “observação histórica” e não contabiliza isso como PASS retroativo de gate de banco.

## Outra decisão possível

Manter `none` como `source_pending` até surgir prova por tarefa ou uma mudança de especificação governada. Nesse caso o critério de zero inválidas e os selos continuam bloqueados; não remover arquivos do escopo do gate.

Esta decisão isolada não resolve `CTG` com sufixo, posições/status legados, executor/composição, títulos longos ou as quatro alegações `INV-*` ausentes do trace. Essas classes requerem tabela de resolução própria antes de qualquer afirmação de zero inválidas.
