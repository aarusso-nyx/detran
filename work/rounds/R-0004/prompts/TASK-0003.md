## Definições que valem como contrato

- Assinatura pública: `get(key, { agencyId?, on?, required? })`. O mapeamento fechado de prefixo
  para surface é `rait|collection|deadline|session` → `rait`; `teat|sync` → `teat`;
  `portal|privacy` → `portal`; `est` → `est`; `dashboard` → `dashboard`. Qualquer outro prefixo
  falha fechado. Precedência e vigência são exatamente as de TASK-0002.
- Nunca aceite `tenant_id`/actor no payload. Capture ambos do `RequestContext`.
- PUT `/v1/ops/parameters/:key`: `@Resource('ops:parameter')`, `@Action('update')`,
  `@Audit({ action: 'OPS_PARAMETER_UPDATE', entity: 'ops.parameter' })`; exige `If-Match` e
  `Idempotency-Key`; ETag é a versão citada pelo contrato.
- Mutação sempre insere nova versão, fecha a anterior quando aplicável, emite
  `PARAMETRO_ALTERADO` na outbox dentro da mesma transação e invalida cache após sucesso.
- Códigos permitidos: `RAIT.IF_MATCH_REQUIRED`, `RAIT.VERSION_CONFLICT`,
  `RAIT.IDEMPOTENCY_REPLAY`, `RAIT.PARAMETER_LEGAL_READONLY`,
  `RAIT.PARAMETER_EFFECTIVE_DATE_PAST`, `RAIT.PARAMETER_SOURCE_PENDING`. Contexto só ids/tokens.
- Nesta rodada, `required=true` sobre fonte pendente só possui alias público
  `RAIT.PARAMETER_SOURCE_PENDING`. Não crie aliases para `BOAT.RETENTION_UNDEFINED` nem
  `DASH.CELL_THRESHOLD_UNDEFINED`; eles ficam adiados até os primeiros consumidores/fronts,
  conforme ADR-0021 Decisão 2.
- Cache é por tenant + key + agency + data; nunca compartilhe entre tenants. Uma invalidação não
  pode limpar dados de outro tenant.
- Não implemente a view `inf.normative_agency_parameter` e não toque no módulo normativo.
