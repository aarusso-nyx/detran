## Definições que valem como contrato

- Happy path: uma linha numérica, uma string, uma pendente `—`, uma legal e uma flag `F`; confirma
  surface, JSON tipado, `source_pending`, `legal_readonly`, `decision_ref`, provenance/hash, ordem
  lexical e SQL idempotente.
- Determinismo: duas execuções byte a byte iguais; alteração de fonte muda hash e apenas os
  registros afetados.
- Negativos obrigatórios, cada um exit 1 com arquivo/linha/chave: header incorreto, célula ausente,
  chave duplicada, status inválido, `pend.` typo `no`, flag não booleana, `—` sem pending,
  `decision_ref` órfã, prefixo incompatível e artefato gerado stale.
- Uso em código: fixture com chave literal conhecida passa; chave literal ausente falha; diretório
  de teste/dist/node_modules não conta.
- Os testes black-box das ferramentas provam que somente `F` entra nos dois artefatos TypeScript,
  que `backend/app/src/generated/parameter-flags.ts` é emitido e que o nome de env é estável.
- O teste unitário do app importa e chama somente a API pública `detranFeatureFlagSet()`; não
  importa nenhum artefato gerado. Pela API pública, prova defaults gerados,
  `teat.speed_meters=false`, precedência dos overrides `DETRAN_FEATURE_*` e preservação do alias
  legado `DETRAN_FEATURE_SPEED_METERS` para `teat.speed_meters`.
- O teste não depende de rede, banco ou relógio real.
