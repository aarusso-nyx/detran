# R-0025 — matriz de 64 métodos de comando FE (CTG-0001)

**Papel:** Architect (Constitution arts. 6–7). **Base de reconferência:** `origin/main` em `d8c5d72a` (2026-09-29). A worktree e o `origin/main` local posterior têm os mesmos blobs nos caminhos de fonte abaixo. A classificação é a OD-R25-001; nenhuma linha é implementação entregue.

## Escopo e leitura

- Uma linha = um método com `throw new RaitCommandUnavailableError` nos seis clientes indicados. `R-01` é a etapa CRUD dos vereditos de `F-01`; não é uma 65ª linha. `R-02…R-36` são as 35 linhas desalinhadas.
- Rotas relativas a `/v1/inf/rait`, salvo path absoluto. `F-nn` traz path e `operationId` **propostos** na análise, ausentes da base. `—` em operação/rota significa ausência verificada. Chave efetiva é a rota `@Resource` + `@Action`; em `F-nn`, é chave alvo proposta, sem garantia de política efetiva até CTG-0002/0003. `S` prevalece sobre `T` na política.
- `DTO FE` é o tipo da assinatura atual; a coluna de ajuste preserva o corpo/alvo exigido na análise. `CommandBody` não prova compatibilidade com o DTO backend. Pós-estado é a transição ou efeito normativo esperado; quando o código/fonte não fixa o valor, consta `source_pending` na nota. Erro é código **catalogado para a condição** (não afirma que o backend já o emite); os erros comuns de schema, autorização, tenant, If-Match e versão estão no catálogo §3.1–3.2.
- Fontes por linha: `U` = `apps/rait/web/src/app/data/api/<cliente>.client.ts`, método citado; `G` = `work/rounds/R-0025/command-gap-analysis.md` §3–§5; `C` = os sete `docs/framework/contracts/*.commands.openapi.json` indicados abaixo; `B` = `backend/domains/inf/*/src/{handwritten,controllers}` e, para #45, `backend/domains/ops/parameter`; `P` = `backend/domains/shared/src/policy.ts`; `A` = `docs/framework/arch/rait-web-frontend.md` §6.6–§7 e `rait-error-catalog.md` §3. A nota específica de cada linha é a evidência da diferença.
