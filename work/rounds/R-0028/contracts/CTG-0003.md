## Política de modo (OD-R28-001, decidida pelo Owner)

| Modo                   | Quando                                                                                                                                                                          | Gateway                        | Efeito                                                                                                                                                                                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `homologacao` (padrão) | configuração padrão dos hosts TEAT (ADR-0033; `apps/teat/web/angular.json` `defaultConfiguration: "homologation"`) e qualquer ausência ou valor desconhecido do seletor de modo | `HomologationBoatCrashGateway` | dados sintéticos, determinísticos e segregados; respostas nomeadas como simulação (`simulated: true`); nenhuma chamada de mutação produtiva; **nenhum item na fila real de sincronização** (ADR-0033 §Fronteira 2: não sincronizam); selo `homologacao` nas telas |
| `real`                 | só por seleção explícita e não padrão, provada na stack local e no e2e (OD-R28-001)                                                                                             | `ApiBoatCrashGateway`          | fila `crash-record` do host e cliente gerado `@detran/api-clients` (BP-EST-CRASH-001); as rotas mantêm o selo `homologacao` até a ADR de release; S-06/W-05 fail-closed (`binding-matrix.md` §Fail-closed)                                                        |

Mecanismo de seleção: token `BOAT_CRASH_MODE` (`InjectionToken<BoatCrashMode>`), cujo padrão é
`homologacao`. O modo `real` vem só de configuração de build não padrão. É provisório,
`source_pending:OD-R28-019`, e deve ser reconferido com R-0024. A ADR-0033 não é ampliada.

## Interface

Arquivo: `apps/boat/mobile/src/lib/gateway/boat-crash.gateway.ts` (interface, tipos e tokens).
Implementações: `apps/boat/mobile/src/lib/gateway/api-boat-crash.gateway.ts`
(`ApiBoatCrashGateway`) e `apps/boat/mobile/src/lib/gateway/homologation-boat-crash.gateway.ts`
(`HomologationBoatCrashGateway`).

```ts
export type BoatCrashMode = 'homologacao' | 'real';
export const BOAT_CRASH_MODE: InjectionToken<BoatCrashMode>; // padrão 'homologacao'
export const BOAT_CRASH_GATEWAY: InjectionToken<BoatCrashGateway>;
export const BOAT_CRASH_QUEUE: InjectionToken<BoatCrashQueuePort>; // fornecido pelo host

/** operationIds de BP-EST-CRASH-001.commands.openapi.json (13). */
export type BoatCrashCommandId =
  | 'boatCrashRecordStart'
  | 'boatCrashRecordRecord'

  | 'boatCrashRecordSatelliteAdd';

  | 'boatCrashRecordRenaestRead'
  | 'boatCrashRecordReport'

  | 'listCrashSubjectRequest';

export interface BoatCrashCommandInput {
  readonly id: string; // path {id}, uuid
  readonly ifMatch: string; // cabeçalho if-match obrigatório (OpenAPI)
  readonly kind?: string; // só SatelliteAdd/Rectify; valores source_pending:OD-R28-006

  readonly mode: BoatCrashMode;

}

  enqueue(

      entityType: 'crash-record';
      localEntityId: string;

      contentHash: string;

    }>,
  ): Promise<Readonly<{ localEntityId: string; status: 'received' }>>;
}
export interface BoatCrashGateway {
  readonly mode: BoatCrashMode;
  finalize(
    payload: CrashRecordPayload,

      localEntityId: string;
```

`CrashRecordPayload` é o payload canônico de `boat-route-contract.md` §4 (`record`,
`vehicles[]`, `people[]`, `victims[]`, `sceneDuties[]`, `damages[]`, `witnesses[]`, `sketch`,
`evidenceLocalIds[]`, `links[]`). O schema JSON canônico entregue em WP-B3 é a referência de
forma, e o nome do tipo gerado deve ser reconferido na retomada.

Regras do gateway:

1. **Online (`ApiBoatCrashGateway`):** cada `operationId` chama a função gerada para ele em
   `packages/api-clients/src/generated/BP-EST-CRASH-001{,.commands}.ts`, com o verbo e o path da
   `binding-matrix.md`. Envia `if-match` em todo comando `POST` e nada que o OpenAPI não declare:
   sem `Idempotency-Key`, sem `?purpose=` e sem filtros enquanto OD-R28-005 estiver aberta. Os
   testes provam essa ausência.
2. **Offline (`finalize`):** no modo `real`, `finalize` chama `BOAT_CRASH_QUEUE.enqueue` com
   `entityType: 'crash-record'`. O host aplica pela fila do TEAT
   (`POST /v1/ops/offline-sync/sync-batches` → `CrashSyncApplier`). Nada bloqueia por falta de
   rede (`boat-frontends.md` §2.8). `idempotencyKey` e `contentHash` vêm de `crashReviewSchema`
   (`idempotency_key`, `content_hash`).
3. **Homologação (`HomologationBoatCrashGateway`):** não injeta `BOAT_CRASH_QUEUE` nem
   `HttpClient`. `finalize`, `execute` e `read` resolvem `simulated: true` com fixtures
   sintéticas de tokens canônicos (estados de [WF-BOAT-001], gravidade federal), em arquivo
   `apps/boat/mobile/src/lib/gateway/homologation-fixtures.ts`. Os ids das fixtures são
   determinísticos e identificáveis como homologação.
4. **Fail-closed:** no modo `real`, `read('listCrashVictim', …)` e `finalize` com
   `record.severity` ≠ `SEM_VITIMA` rejeitam antes de qualquer E/S com o erro de catálogo
   `BOAT.RETENTION_UNDEFINED` (`boat-error-catalog.md` §2: operação que exige retenção definida
   enquanto DT-049 pendente), até OD-R28-013. `victims[]` nunca sai do dispositivo no modo real.
5. **Erros:** respostas HTTP viram o código `BOAT.*` do envelope. Falha de porta chega como
   `BoatPortError` (CTG-0002). O gateway não traduz texto.
6. Nenhum acesso a RENAEST/SENATRAN: `transmit`/`rectify` vão ao backend, que usa o adapter
   (ADR-0003).

## Providers nos boundaries do TEAT mobile

Arquivo novo no host: `apps/teat/mobile/src/app/features/sinistro/sinistro.providers.ts`,
exportando `provideSinistroBoat(): Provider[]` com:

- `provideBoatHomologationPorts()` (CTG-0002);

no decorator (ou na classe base `BoatRouteBoundary`, se o padrão de R-0024 permitir). A página
BOAT, criada por `NgComponentOutlet` dentro do boundary, herda o injetor. Não se toca
`apps/teat/mobile/src/main*.ts` (lock de R-0024) nem `resolveBoatRoute`/`TEAT_BOAT_EXTENSION`.
É preciso reconferir o ponto de injeção com R-0024.
