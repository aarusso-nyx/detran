# R-0022 — small immutable retention and download records

Architect/F1; concrete refinement of bf863. Existing original capture/provenance/closure/source bytes remain immutable historical evidence. Mutable registry packuments must not be re-fetched expecting their old full-body SHA. This interface admits independently reviewed small version selections, not a false reconstruction of old packument bytes.

## Common records

Input B3 means an existing small retained regular file `{path,bytes,sha256}` with independently pinned actual bytes. Download descriptor is a different closed type `{url,destination,bytes,sha256,integrity}`: exact approved HTTPS URL, normalized internal fixed output-relative destination, actual retained size/SHA and actual SRI string or null where official Node proof has no SRI. It is an expected downloaded artifact, not a preexisting input file ref. The producer verifies fetched bytes/SRI before extraction; no live latest/range/version selection. Member descriptor `{path,bytes,sha256}` is a safe archive-relative member expectation, not an existing root input B3. Type is determined by its closed parent field, never a generic recursive path walker.

Small version metadata fixture is `{formatVersion,kind,package,version,sourceObservation,versionRecord}`:1, `detran-retained-registry-version`; package/version actual retained strings, versionRecord is the unmodified selected upstream versions[version] object, retained as legal JSON. sourceObservation is `{sourcePath,sourceBytes,sourceSha256,observedAt,selection,serialization}` with historical sourcePath, actual full-packument size/hash/time, selection literal versions[the exact version], serialization literal `UTF16-key-sorted-json-array-order-preserved`. This sourceObservation is historical provenance, deliberately not an active B3 reference to a body required on clean CI. Independent F1/F3 extraction review must compare the derivative to the actual still-retained original body before its actual small fixture SHA enters policy. No mutation/rewrite of that original observation.

CI independently validates the admitted derivative SHA, selected package/version/dist/dependency facts, exact archive SRI/size/SHA and actual tar package.json. It cannot recompute the omitted old full packument SHA and must never claim it did. Original full bodies remain in immutable historical custody outside the committed small fixture set; retaining their old hash is not a byte archive. The immutable derivative and actual independent review are explicit new portable input anchors, not self-approved recomputed manifests. This preserves strong publication/archive/manifest admission without hundreds of MB of mutable registry responses in Git.
