# Adotantes

Guias para equipes que operam a suíte ou fazem integração com ela, como DETRANs
estaduais e órgãos autuadores.

## Manuais de usuário

Os manuais por perfil ficam em `docs/adopters/manuais/`. Pela decisão
OD-UD-002, o site público publica o manual do cidadão, o glossário e o trecho
cidadão do FAQ.
