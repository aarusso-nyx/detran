# DEVAI trusted local RC verification

Source: `.github/workflows/devai-local-rc-verify.yml`, generated by the installed DEVAI binding boundary. It reads candidate content as inert data, materializes the independently pinned verifier, binds the exact candidate tree to protected immutable evidence and publishes the verified-local-rc check. PACKAGES_READ_TOKEN supplies read-only registry authentication. Missing evidence or a failed binding blocks verification; rerunning without a valid exact-tree proof does not repair the failure. Regenerate this workflow through init upgrade or init bind rather than editing protected verifier identities manually.
