Registro único das pendências abertas do programa, consolidado de `_meta/backlog.md`, das seções
§Residual dos `APP.md` e das decisões de steering. Existe para que possam ser criadas como issues
de repositório sem garimpo — ver `_meta/issues-export.py`.

**Tipos** — determinam quem age, e é a única classificação que importa na prática:

| Tipo                | Quem resolve                                        | Natureza                                                |
| ------------------- | --------------------------------------------------- | ------------------------------------------------------- |
| `blocker`           | Owner, agora                                        | impede construção hoje                                  |
| `owner-decision`    | Owner                                               | escolha de produto/calibração; não depende de terceiros |
| `legal-validation`  | advogado humano                                     | parecer sobre norma ambígua, conflitante ou silente     |
| `institutional-ask` | canal externo (DETRAN-AM, SENATRAN, CGE-AM, CETRAN) | depende de documento ou informação que não é pública    |
| `research-capture`  | pesquisa                                            | norma ou dado a capturar no corpus                      |
| `engineering`       | time de desenvolvimento                             | débito de código identificado, com correção conhecida   |
| `kb-consistency`    | rodada de KB                                        | divergência interna entre artefatos                     |

Prioridade: `P0` bloqueia construção · `P1` bloqueia uma fase ou expõe risco jurídico alto ·
`P2` necessário antes de produção · `P3` melhoria ou dívida conhecida.
